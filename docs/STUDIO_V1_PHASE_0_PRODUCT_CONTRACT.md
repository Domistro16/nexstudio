# Studio V1 Phase 0 Product Contract

Status: SEALED

- Public families: Explainer, Whiteboard, Stickman, Editorial Motion only.
- One dominant action per state; no timeline editor.
- First guest prompt is production intent and must survive auth/payment/reopen.
- Projects are not public navigation; work lives in Dashboard.
- Complimentary pre-payment output is a bounded text production plan, not full Creative Lock or valuable detailed storyboard package.
- Pricing is server-authoritative at $2 per finished minute; USD balance, not credits.
- Configurable first-production welcome discount; default 10%.
- Payment starts the full NexMind authority path; payment itself never grants Creative Lock.
- Director proposes; constraints validate; renderer executes; QA verifies.
- Full P8 creative state must be hash-bound to engine evidence and independent review before Creative Lock.
- Production UI reports actual states/artifacts only; no fake progress.
- Revisions stay in the same paid production and preserve unaffected locked decisions.
- Public final-output dispatch fails closed until the selected family is release-certified.
