# NexStudio Public Homepage Visual Authority

Date: 2026-08-15
Status: HOMEPAGE VISUAL AUTHORITY — follows the approved 2026-08-14 Hero Authority

## Scope

This authority owns only the public NexStudio homepage and its public navigation treatment. It does not redesign or supersede Dashboard, Production Room, Screening Room, billing, authentication, production logic, certification, NexMind, or the public four-family capability registry.

The approved hero remains the first visual benchmark. The homepage below it must feel like the same product, not a collection of marketing sections.

## Public experience sequence

1. Hero / creation composer
2. Certified Work stage
3. Three-step production relationship
4. Four production-family bands
5. Continuity / quality confidence room
6. Final creation composer
7. Footer

## Visual language

### Foundation

- Warm near-neutral public canvas; never pure white across the full page.
- Dark screening/confidence rooms provide deliberate scene changes and page rhythm.
- Violet, rose, sky, peach and mint are atmospheric accents, not generic SaaS brand blocks.
- Family colour is present quietly at rest and becomes richer on hover/focus.
- Real certified films, when available, own the strongest colour and movement in the Work stage.

### Surfaces

- Creation composer: soft translucent material, fine border, subtle internal colour wash, restrained elevation.
- No generic feature cards or floating AI widgets.
- Family presentation uses full-width editorial bands rather than card grids.
- Confidence points use structural rules and typography rather than boxed cards.

### Typography

- Large editorial headings use tight display spacing and short line lengths.
- Supporting copy stays quiet and narrow.
- Monospace/numeric micro-labels are reserved for sequence markers and structural state.
- Customer copy must not expose certification-registry jargon, internal creative authorities or production-engine implementation language.

## Motion language

- Motion library: `motion` for reveal, layout and state continuity.
- GSAP is not required while no certified media-driven scroll sequence exists. It may be introduced later only for a real cinematic media transition that Motion cannot express cleanly.
- Approved hero Light Rays remain the only deliberately adopted recognizable effect.
- Ambient hero blooms are the only CSS keyframes currently approved on the public homepage.
- Family colour intensifies on hover/focus without perspective gimmicks.
- Reduced motion collapses non-essential animation.

## Certified media rule

The homepage never invents showcase work.

`getPublicVideoTypes()` remains the public gate. Work media renders only from video types already admitted by that selector and only when the required preview video and poster are present. When certified work is unavailable, the Work section uses the truth-preserving designed empty state instead of fake posters, synthetic film frames, borrowed footage or hand-rescued demos.

## Creation composer rule

The hero and closing composer share the same prompt state, source/reference state, recommendation flow and Create action.

Public file selection remains staged locally until the existing authenticated secure-ingestion boundary can take authority. The homepage must not bypass upload security for visual convenience.

## Responsive rules

### Desktop

- Hero remains centered and dominant.
- Work stage uses an editorial split and, when certified media exists, asymmetrical media composition.
- Process is three-column.
- Family bands retain large type and horizontal information hierarchy.
- Confidence room uses asymmetry and a two-column quality grid.

### Tablet

- Major editorial headings become single-column.
- Work empty state stacks.
- Family copy becomes vertical inside each band.
- Confidence room becomes one principal column while preserving the structural quality grid.

### Mobile

- Hero keeps the approved compact composer.
- Work and process stack vertically.
- Real Work media becomes a horizontal snap rail when available.
- Family bands remain full-width and tactile, never card carousels.
- Continuity becomes horizontally scrollable only for the compact state ribbon; core copy remains vertical.
- Closing composer preserves Add files, Add reference and Create in one compact action row.

## Invariants

Do not:

- reintroduce Studio V1 visual language;
- insert fake work to make the page look populated;
- add generic SaaS feature-card grids;
- add AI orbs, neural diagrams, pulsing live dots, fake progress or thinking animation;
- add recognizable React Bits effects beyond the modified Light Rays authority;
- expose NexMind or renderer internals;
- alter production/auth/billing/workspace contracts from this visual authority.
