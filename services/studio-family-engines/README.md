# Studio V1 family execution bridge

This service translates an already-directed NexMind P8 final board into one of the four current production bodies. It is an execution adapter, not a creative Director.

Implemented internal-review evidence adapters:

- Explainer — P8-controlled execution-only authored-art body with StudioFamilyExecutionFidelityV1; commercial taste is post-render Final Producer + independent perceptual auditor only.
- Whiteboard — current semantic compiler/runtime and renderer.
- Stickman — V5.1 skin-safe unified performance/cast runtime.
- Editorial Motion — current faceless/editorial Level-5/Level-7 renderer boundary.

Every adapter can create real MP4 + 48 kHz audio + contact-sheet evidence for internal review. Public paid final-output dispatch remains fail-closed until the corresponding family authority is independently certified for release.

Required engine roots are installed from `engine_sources/` with `python scripts/install-engines.py`. See `.env.example`.
